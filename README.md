The purpose of this scenario is to be an enjoyable gameplay experience for the player.

The player is expected to navigate the duck that they are controlling through three separate levels each consisting of five waves of enemy geese that will be attempting to stop you. 
The player will need to adapt to new enemies as they progress, and a new weapon on each level.

Functionality of this game includes movement of the player, aiming, and a dodge ability. The player will also have the chance to select an upgrade between each wave of enemies. 
These upgrades include modifiers to the player’s attack speed, damage, speed, health, and damage reduction. These upgrades only persist for the level that the player is on.
